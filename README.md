# Danishbir Singh - Portfolio

Personal portfolio website showcasing AI/ML and software engineering projects.

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** GSAP, Framer Motion
- **Deployment:** Vercel, Supabase

## Features

- 🎨 Monochromatic design aesthetic
- ✨ Interactive animations
- 📱 Responsive (desktop-first)
- ⚡ Optimized performance
- 🎯 SEO friendly
